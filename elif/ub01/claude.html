Çözümler adım adım, animasyonlu anlatım

Not: Burada ℕ = {0, 1, 2, …} kabul edilmiştir (0 dahil).

Soru 1: Küme gösterimleri

(a) Kompakt gösterim

(i) Çift doğal sayılar: {2k | k ∈ ℕ} (ya da {n ∈ ℕ | n çift}). (ii) 0 ile 1 arası rasyoneller (uçlar hariç): {x ∈ ℚ | 0 < x < 1}. (iii) −7'den küçük tam sayılar: {x ∈ ℤ | x < −7} = {…, −9, −8}. (iv) Pozitif ve π'ye eşit veya küçük reeller: {x ∈ ℝ | 0 < x ≤ π} = (0, π].

(b)(i) {x∈ℚ | −3≤x<10} ∩ {x∈ℤ | x<9}

Kesişimdeki x hem rasyonel aralıkta (−3 ≤ x < 10) hem tam sayı hem x < 9 olmalı. Her tam sayı rasyoneldir. Yani koşullar: x ∈ ℤ, −3 ≤ x < 9. = {−3, −2, −1, 0, 1, 2, 3, 4, 5, 6, 7, 8} (12 eleman)

(b)(ii) {x∈ℤ | −2<x≤π} ∖ {x∈ℕ | x≤2}

π ≈ 3,14: ilk küme {−1, 0, 1, 2, 3}. İkinci küme (0 ∈ ℕ): {0, 1, 2}. Fark: 0, 1, 2 atılır. = {−1, 3} (ℕ 0'sız tanımlansaydı sonuç {−1, 0, 3} olurdu.)

Soru 2: Venn diyagramları

Boyalı bölge, işlemin sonucunu gösterir.

(a) M ∩ N ∩ O

Üç dairenin ortak bölgesi.

(b) M ∩ (M ∪ N)

Emilim: M ⊂ M∪N olduğundan sonuç M'in kendisi.

(c) M ∖ (N ∩ O)

M'nin tamamı, N∩O ile örtüşen kısım hariç.

(d) (M ∖ N) ∪ (N ∖ M)

Simetrik fark: yalnızca birinde olanlar. O dairesi dahil değil.

(e) ((M∩N)∖O) ∪ ((N∩O)∖M)

N'nin içinde, M ve O'dan tam birine ait olan iki parça. M∩N∩O ve yalnız N dahil değil.

Soru 3: (A∩B) ∪ C = (A∪C) ∩ (B∪C)

Küme eşitliği için iki kapsama gerekir. Eleman alıp durumlara ayırıyoruz.

(a) ⊂ yönü

x ∈ (A∩B) ∪ C alalım. Yani x ∈ A∩B veya x ∈ C. Durum 1: x ∈ A∩B. O zaman x ∈ A ve x ∈ B. Dolayısıyla x ∈ A∪C ve x ∈ B∪C. Durum 2: x ∈ C. O zaman x ∈ A∪C ve x ∈ B∪C. İki durumda da x ∈ (A∪C) ∩ (B∪C). ∎

(b) ⊃ yönü

x ∈ (A∪C) ∩ (B∪C) alalım: x ∈ A∪C ve x ∈ B∪C. Durum 1: x ∈ C. O zaman hemen x ∈ (A∩B) ∪ C. Durum 2: x ∉ C. x ∈ A∪C ⇒ x ∈ A. x ∈ B∪C ⇒ x ∈ B. Yani x ∈ A∩B, dolayısıyla x ∈ (A∩B) ∪ C. ∎ İki kapsama birleşince eşitlik kanıtlanır.

Soru 4: Kartezyen çarpım ve kuvvet kümesi

A = {0, 2}, B = {1, b}, b ∈ ℝ, b ≠ 1.

(a)(i) A × B

A × B = {(0,1), (0,b), (2,1), (2,b)} b ≠ 1 olduğundan 4 eleman birbirinden farklı: |A×B| = 4.

(a)(ii) P(A × B): 2⁴ = 16 eleman

Kısaltma: a = (0,1), c = (0,b), d = (2,1), e = (2,b). 0 elemanlı: ∅ 1 elemanlı: {a}, {c}, {d}, {e} 2 elemanlı: {a,c}, {a,d}, {a,e}, {c,d}, {c,e}, {d,e} 3 elemanlı: {a,c,d}, {a,c,e}, {a,d,e}, {c,d,e} 4 elemanlı: {a,c,d,e} = A × B 1 + 4 + 6 + 4 + 1 = 16. (Her eleman için "var/yok": 2⁴.)

(b) P(C∩D) = P(C) ∩ P(D)

⊂: Y ∈ P(C∩D) ⇒ Y ⊂ C∩D. Her y ∈ Y için y ∈ C ve y ∈ D. Yani Y ⊂ C ve Y ⊂ D, dolayısıyla Y ∈ P(C) ∩ P(D). ⊃: Y ∈ P(C) ∩ P(D) ⇒ Y ⊂ C ve Y ⊂ D. Her y ∈ Y için y ∈ C ve y ∈ D, yani y ∈ C∩D. Böylece Y ⊂ C∩D, yani Y ∈ P(C∩D). ∎

Soru 5: Eleman sayısı (kardinalite)

(a) |A∩B| = 2 ve |A∪B| = 3

A = {1,2,3}, B = {1,2} A∩B = {1,2} (2 eleman), A∪B = {1,2,3} (3 eleman). ✓

(b) |A∪B| = |B|

A = ∅, B = {1}: A∪B = {1}, |A∪B| = 1 = |B|. ✓ Genel olarak A ⊂ B olduğunda hep sağlanır.

(c) |C∩D| ≤ |C|

C, ayrık iki parçaya ayrılır: C = (C∩D) ∪ (C∖D). Ayrık olduğu için |C| = |C∩D| + |C∖D|. |C∖D| ≥ 0 olduğundan |C∩D| ≤ |C|. ∎ Eşitlik ne zaman? |C∖D| = 0 ⇔ C∖D = ∅ ⇔ C ⊂ D. Yani eşitlik tam olarak C ⊂ D iken olur (o zaman C∩D = C).
