Aufgabe 1: Mengenschreibweisen

(a) Kompakte Schreibweise

(i) Gerade natürliche Zahlen: {2k | k ∈ ℕ} (oder {n ∈ ℕ | n gerade}). (ii) Rationale Zahlen strikt zwischen 0 und 1: {x ∈ ℚ | 0 < x < 1}. (iii) Ganze Zahlen kleiner als −7: {x ∈ ℤ | x < −7} = {…, −9, −8}. (iv) Positive reelle Zahlen höchstens π: {x ∈ ℝ | 0 < x ≤ π} = (0, π].

(b)(i) {x∈ℚ | −3≤x<10} ∩ {x∈ℤ | x<9}

Jedes x der Schnittmenge muss im rationalen Intervall −3 ≤ x < 10 liegen, ganzzahlig sein und x < 9 erfüllen. Jede ganze Zahl ist rational. Es bleiben die Bedingungen: x ∈ ℤ, −3 ≤ x < 9. = {−3, −2, −1, 0, 1, 2, 3, 4, 5, 6, 7, 8} (12 Elemente)

(b)(ii) {x∈ℤ | −2<x≤π} ∖ {x∈ℕ | x≤2}

Wegen π ≈ 3,14 ist die erste Menge {−1, 0, 1, 2, 3}. Die zweite Menge (0 ∈ ℕ): {0, 1, 2}. Differenz: 0, 1 und 2 werden entfernt. = {−1, 3} (Wäre 0 nicht in ℕ enthalten, erhielte man {−1, 0, 3}.)

Aufgabe 2: Venn-Diagramme

Die eingefärbte Fläche zeigt das Ergebnis der Mengenoperation.

(a) M ∩ N ∩ O

Der gemeinsame Schnittbereich aller drei Kreise.

(b) M ∩ (M ∪ N)

Absorptionsgesetz: Da M ⊆ M∪N gilt, ist das Ergebnis Mselbst.

(c) M ∖ (N ∩ O)

Die ganze Menge M, außer ihrem Schnitt mit N∩O.

(d) (M ∖ N) ∪ (N ∖ M)

Symmetrische Differenz: Elemente, die genau in M oder in N liegen. O ist dafür unerheblich.

(e) ((M∩N)∖O) ∪ ((N∩O)∖M)

Innerhalb von N die beiden Bereiche, die zu genau einer der Mengen M und O gehören. M∩N∩O und der Bereich nur in N sind ausgeschlossen.

Aufgabe 3: (A∩B) ∪ C = (A∪C) ∩ (B∪C)

Für die Mengengleichheit müssen wir beide Inklusionen beweisen. Dazu wählen wir ein Element und unterscheiden Fälle.

(a) Inklusion ⊆

Sei x ∈ (A∩B) ∪ C. Dann gilt x ∈ A∩B oder x ∈ C. Fall 1: x ∈ A∩B. Dann x ∈ A und x ∈ B. Folglich x ∈ A∪C und x ∈ B∪C. Fall 2: x ∈ C. Dann gehört x sowohl zu A∪C als auch zu B∪C. In beiden Fällen gilt x ∈ (A∪C) ∩ (B∪C). ∎

(b) Inklusion ⊇

Sei x ∈ (A∪C) ∩ (B∪C). Also x ∈ A∪C und x ∈ B∪C. Fall 1: x ∈ C. Dann gilt unmittelbar x ∈ (A∩B) ∪ C. Fall 2: x ∉ C. Aus x ∈ A∪C folgt x ∈ A; aus x ∈ B∪C folgt x ∈ B. Also x ∈ A∩B, und damit x ∈ (A∩B) ∪ C. ∎ Beide Inklusionen zusammen beweisen die Mengengleichheit.

Aufgabe 4: Kartesisches Produkt und Potenzmenge

A = {0, 2}, B = {1, b}, b ∈ ℝ, b ≠ 1.

(a)(i) A × B

A × B = {(0,1), (0,b), (2,1), (2,b)} Da b ≠ 1, sind die vier Paare verschieden: |A×B| = 4.

(a)(ii) P(A × B): 2⁴ = 16 Elemente

Abkürzungen: a = (0,1), c = (0,b), d = (2,1), e = (2,b). Mit 0 Elementen: ∅ Mit 1 Element: {a}, {c}, {d}, {e} Mit 2 Elementen: {a,c}, {a,d}, {a,e}, {c,d}, {c,e}, {d,e} Mit 3 Elementen: {a,c,d}, {a,c,e}, {a,d,e}, {c,d,e} Mit 4 Elementen: {a,c,d,e} = A × B 1 + 4 + 6 + 4 + 1 = 16. (Jedes Element ist entweder enthalten oder nicht: 2⁴.)

(b) P(C∩D) = P(C) ∩ P(D)

⊂: Y ∈ P(C∩D) ⇒ Y ⊆ C∩D. Jedes y ∈ Y liegt somit in C und D. Also Y ⊆ C und Y ⊆ D; daher Y ∈ P(C) ∩ P(D). ⊃: Y ∈ P(C) ∩ P(D) ⇒ Y ⊆ C und Y ⊆ D. Jedes y ∈ Y liegt daher in C∩D. Somit Y ⊂ C∩D, also Y ∈ P(C∩D). ∎

Aufgabe 5: Kardinalität

(a) |A∩B| = 2 und |A∪B| = 3

A = {1,2,3}, B = {1,2} A∩B = {1,2} (2 Elemente), A∪B = {1,2,3} (3 Elemente). ✓

(b) |A∪B| = |B|

A = ∅, B = {1}: A∪B = {1}, |A∪B| = 1 = |B|. ✓ Allgemein gilt dies immer, wenn A ⊆ B.

(c) |C∩D| ≤ |C|

C zerfällt in zwei disjunkte Teile: C = (C∩D) ∪ (C∖D). Wegen der Disjunktheit gilt |C| = |C∩D| + |C∖D|. Da |C∖D| ≥ 0 gilt, folgt |C∩D| ≤ |C|. ∎ Wann gilt Gleichheit? |C∖D| = 0 ⇔ C∖D = ∅ ⇔ C ⊂ D. Gleichheit gilt genau dann, wenn C ⊆ D ist (dann C∩D = C).
